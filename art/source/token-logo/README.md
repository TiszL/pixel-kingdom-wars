# KEEP Token Logo Assets

Source: the in-game `ui_icon_keep` pixel-art coin (assets-v2), exported standalone at token-logo size.

| File | Size | Notes |
|---|---|---|
| `keep_token_logo.svg` | 24×24 vector | Original source art, unedited. |
| `keep_token_logo_512.png` | 512×512, transparent | Static logo — faithful upscale, no effects. Use this for the on-chain token image if you want a static mark. |
| `keep_token_shine_512.gif` | 512×512, transparent | Animated version: a diagonal gold gleam sweeps across the coin once every ~2s, then rests. Loops forever. Use this if you want an animated token image. |

Both the PNG and GIF are crisp pixel-art (no anti-aliasing, no resampling blur) and keep the coin's original house palette. Pick whichever one before deploying — same art either way, so swapping later is safe.
