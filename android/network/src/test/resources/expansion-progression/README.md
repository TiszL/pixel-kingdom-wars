# Source expansion policy reference

Test-only fixture, generated by executing the current source `claimRect`,
`plotVersionForClaim`, `plotBounds` and `expansionOffer`. Gameplay numbers remain
in source constants. The fixture records source file hashes and all thirteen
claim states; it does not activate a native content pack.

From the native root, run the source checkout's `apps/api/node_modules/.bin/tsx`
with `network/src/test/resources/expansion-progression/generate.mts` and the
absolute source checkout path. Add `--check` to compare without rewriting.
Review changed policy and hashes before regenerating.

The native tests compare Keep gates and exact lamports, original purchase
identity, full building footprints, signed wall positions and construction
receipt recovery. Historical requests keep their recorded plot geometry.
