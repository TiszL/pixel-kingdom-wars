# World v2 pack export (D-186)

`pm1-cb8faa56909faa31/` is the new world's pack exactly as the Android client 0.6.0 bundles it: native's 166-file
selection (31,793,761 bytes) of concept pack `pm1-cb8faa56909faa31`, plus native's own `content.json`, byte for byte.

- **Generated bytes, not masters.** Do not edit anything here. The masters stay off main; this copy is tracked only
  because the pack cannot be rebuilt from git and deploy builds from a fresh clone.
- **Provenance.**
  - `content.json` sha256 `60ac8710…c725` is native `pkw-android-globe` `app/src/main/assets/world/content.json`
    at `globe-native` 7b5075b.
  - It pins `02e9da84` (`globe-realms-veil`), the GLSL and pack lock, and pack-manifest sha256 `ac241498…9007`.
  - On 2026-09-27 every file was checked three ways: against that manifest, against the concept pack on disk, and
    against native's installed copy. There were no mismatches.
  - The selection is native's `tools/world-debug-content.mjs`. chart16 FAR pages are skipped, as native skips them.
- **Publishing.** `pnpm assets:world` (the last step of `pnpm assets`) verifies every file against `content.json` and
  copies the export to `apps/web/public/atlas/world-v2/<packVersion>/`. The web fetches it from there on demand. It is
  outside the offline pack and the api image.
- **Re-pinning.** Add a new `<packVersion>/` directory, update `WORLD_V2_EXPORT` in `scripts/src/world-bundle.ts` and
  `WORLD_V2_PACK_VERSION` in `apps/web/src/ui/fantasy/worldv2/packUrl.ts` in the same commit, and delete the old
  directory.
