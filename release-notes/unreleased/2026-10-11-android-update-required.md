---
title: Older Android versions must update to keep playing
category: android
platforms: android
requires: none
---
Every Android version before 0.7.0 must update before it can build, train or fight, because the servers now run a battle engine that already knows the buildings coming with onchain gameplay; battles against today's bases play as before. Every 0.6 version updates inside the app and keeps your kingdom and wallet exactly as they are, while 0.5 versions have no in-app updater and need the new version from the website's Android download. Update and maintenance notices now show the new version and its size when known, and point to the Solana dApp Store if an install cannot finish.
